# optionally followed by a short reason. parity.py exits 0 only when exactly these checks fail; a listed check that
# passes is reported as XPASS (remove it here), an unlisted check that fails is a regression.

hover.local-inferred-float   var ratio = 3.5 * total shows no type
hover.array-element-type   an array literal shows array, not array<string>
hover.unimported-class   no hover on a class of a package that is not imported yet
definition.unimported-class   no definition for a class of a package that is not imported yet

workspace-symbol.no-open-document   a folder without project.nv is not indexed until a document of it is opened
folding.array-literal   a multi-line [ ... ] literal does not fold
format.case-based-list   no space before { after a base list (based B,C{)
format.case-comments   several spaces before a trailing comment are kept
format.messy-normalised   a blank line directly before the closing brace is kept
format.named-argument-spacing-setting   novus.format.namedArgumentSpacing is not read
